# XJTU Undergraduate Thesis Format Rules

Source template:
- the user-provided XJTU undergraduate thesis template PDF on the Desktop

Purpose:
- This file is a human-readable constraint layer for Prism and other AI writing tools.
- It summarizes the fixed formatting requirements that the thesis should follow.
- If a future LaTeX template implements these rules directly, the executable template is authoritative.

## Global rules

- The thesis must follow the Xi'an Jiaotong University undergraduate thesis template.
- Use computer typesetting.
- Print in black on white paper, double-sided, except where color figures are necessary.
- Main text should be at least 15000 Chinese characters.
- Chinese text uses Songti.
- English text and Arabic numerals use Times New Roman.
- Terminology, symbols, abbreviations, and units must be consistent throughout the thesis.
- New technical terms or abbreviations should be explained when first introduced.

## Page layout

- Paper size: A4.
- Margins:
  - top: 3.0 cm
  - bottom: 2.5 cm
  - left: 2.6 cm
  - right: 2.6 cm
  - binding offset: 0 cm
- Symmetric margins.
- Binding side: left.
- Header distance from page edge: 2.0 cm.
- Footer distance from page edge: 1.75 cm.

## Header and footer

- Every page from the abstract onward must have a header.
- Header font size: fifth size.
- Odd and even pages use different headers.
- Odd-page header: current content title or current chapter title.
- Even-page header: the fixed university thesis name shown in the template.
- Under the header text, draw two horizontal lines.
- Footer should be separated from the body by a thin line about one quarter of page width.

## Page numbering

- Page numbers are placed at the bottom outer side.
- Use plain numbers without extra symbols.
- Front matter uses Roman numerals.
- Main text starts at Arabic page 1.
- Appendix and attached materials continue the page numbering after the references.

## Cover

- Use the university's official unified cover.
- The cover is based on A3 paper wrapping the thesis.
- Thesis title must not exceed 35 Chinese characters.

## Thesis structure

Recommended required order:
1. Cover
2. Chinese abstract
3. English abstract
4. Table of contents
5. Main text, including conclusion
6. Acknowledgements
7. References
8. Appendix
9. Task book
10. Assessment documents
11. Defense result

Optional item:
- main symbol table

## Chinese abstract

- Title: use the fixed two-character Chinese abstract title shown in the template.
- Centered.
- Third-size Songti.
- Two half-width spaces between the two Chinese characters.
- Paragraph spacing: 2 lines before, 1 line after.
- Line spacing: 1.2.
- Body: small-four Songti, first-line indent of 2 characters.
- English and numbers inside the body use Times New Roman.
- No figures, tables, chemical structures, or citation numbers in the abstract.
- Minimum length: 400 Chinese characters.
- Keywords:
  - 3 to 5 items
  - left aligned after one blank line
  - use the fixed Chinese keyword label shown in the template
  - full-width colon
  - keywords separated by full-width semicolons

## English abstract

- Title: `ABSTRACT`
- Centered.
- Third-size Times New Roman.
- Paragraph spacing: 2 lines before, 1 line after.
- Line spacing: 1.2.
- Body: small-four Times New Roman.
- Paragraphs are left aligned and separated by one blank line.
- Content must match the Chinese abstract.
- Keywords:
  - label `KEY WORDS`
  - half-width colon
  - each keyword phrase capitalizes the first letter
  - keywords separated by half-width semicolons

## Table of contents

- Start on a new page.
- Chinese title: use the fixed Chinese table-of-contents title shown in the template.
- Centered, third-size Songti.
- Generally list down to level-3 headings.
- TOC numbering must match the body text numbering.
- Level-1 entries are flush left.
- Each deeper level indents by one additional character.
- Use dot leaders between title and page number.

## Main text

- The body should include introduction, core chapters, and conclusion/outlook.
- Figures and photos must be clear enough for reproduction.
- Body text should be formal academic writing.
- Figures, tables, and equations should be introduced and referenced in the text.

## Headings

- Use hierarchical numbering consistently.
- The template demonstrates levels such as chapter, section, subsection, and deeper enumerations.
- Do not change heading numbering style without explicit instruction.

## Symbols and units

- If many symbols are used, include a symbol table.
- Use legal standard units consistently.
- If a symbol table exists, entries are ordered by Latin uppercase, Latin lowercase, Greek uppercase, then Greek lowercase.

## Figures, tables, and equations

- Figure, table, and equation numbering restarts by chapter.
- Typical examples in the template use forms like:
  - figure: chapter-based figure numbering like `4-1`
  - equation reference: chapter-based equation numbering like `4-1`
- Appendix figures, tables, and equations use appendix-prefixed numbering such as:
  - appendix figure numbering like `A-1`
  - appendix table numbering like `A-1`
  - appendix equation numbering like `A-1`

## Footnotes

- Footnotes are for explanation, commentary, or supplementation.
- Use superscript markers.
- Place them at the bottom of the same page.
- Separate from the body with a thin line about one quarter of page width.

## Acknowledgements

- Title: use the fixed Chinese acknowledgements title shown in the template.
- Centered, third-size Songti.
- Two half-width spaces between the characters.
- Paragraph spacing: 2 lines before, 1 line after.
- Line spacing: 1.2.
- Body: small-four Songti, first-line indent of 2 characters.
- English and numbers use Times New Roman.
- Keep content sincere and factual.
- Length should not exceed 1000 Chinese characters.

## References

- Title: use the fixed Chinese references title shown in the template.
- Centered, third-size Songti.
- Paragraph spacing: 2 lines before, 1 line after.
- Content font: fifth-size; Chinese in Songti, English and numbers in Times New Roman.
- Only include works actually cited in the thesis.
- Prefer authoritative and recent references.
- The template states that the reference list is generally not fewer than 30 items, with recent five-year literature as the main body.
- Follow `GB/T 7714-2015`.
- Use one citation system consistently across the thesis.
- Chinese reference punctuation uses full-width punctuation.
- English reference punctuation uses half-width punctuation.

## Appendix

- Appendices are labeled sequentially as Appendix A, Appendix B, and so on.
- Each appendix title occupies its own line and follows level-1 heading style.
- Usually each appendix starts on a new page.
- Appendix materials may include:
  - original foreign-language paper
  - translation
  - drawings
  - source code
- Headers in the appendix follow the same odd/even-page logic as the main text.
- Page numbers must continue after the references.

## AI editing boundary

Prism and other AI tools should treat the following as fixed constraints:
- page layout
- header and footer logic
- page numbering logic
- heading system
- numbering format for figures, tables, equations, and appendices
- citation standard choice

AI tools should only revise content unless explicitly instructed to change the formatting system itself.
