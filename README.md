# HDSP 历史节点重跑数据整理

本分支用于按任务书要求，围绕项目重要节点进行源码归档、仿真重跑和结果导出整理。

## 目标

覆盖下列 8 个核心节点：

1. 相位反演起点
2. 相位板结构映射
3. 早期热固化闭环
4. Arrhenius 热剂量固化
5. Python/PANN 相位优化转折
6. 出口复场诊断
7. 空化剂量主导固化
8. 三材料并列固化系统

## 目录约定

每个节点目录均包含：

- `src/`
  - 存放从对应历史提交复制出的最小可运行源码快照
- `results_export/`
  - 存放该节点重跑得到的图表、`.mat`、`.csv`、`.json`、`.txt` summary 等本地结果
  - 该目录默认不纳入 Git

## 工作原则

- 早期单脚本节点只复制最小必要源码，不强行恢复整仓库。
- 中后期模块化节点复制主入口及其依赖函数，必要时补运行包装脚本。
- 每个节点至少导出 1 份图表集合和 1 份量化 summary。
- 结果目录只做本地归档，不上传结果数据。

详见 [rerun_manifest.md](./rerun_manifest.md)。
