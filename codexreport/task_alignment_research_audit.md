# 基于任务书的科研对齐审阅报告

本报告以当时检出的 `claude_managed` 分支为依据，审阅对象是当前 `codexreport/` 下五个工作目录、`codex_modules/` 中的代码快照以及 `codexreport/references/` 中的任务书和主要参考文献。旧沟通记忆只作为风险提示使用，核心判断以当前文件、输出指标和文献证据为准。

## 1. 任务书约束提炼

课题题目是“用于超声3D打印的全息超声调制相位板仿真”。任务书对项目的硬要求可以压缩为六条：

1. 系统调研超声3D打印、全息超声调制、相位恢复和相位板机理。
2. 根据打印精度、成型区域和频率确定目标声场参数，并把目标声场相位映射为相位板微结构。
3. 构建相位板、换能器和打印区域的三维仿真模型，材料参数和边界条件需有文献或实验校准依据。
4. 定量评估声压、相位、声强聚焦效果，并识别影响调控性能的关键因素。
5. 结合超声3D打印成型机理，分析声场对材料的驱动效果，尤其是声压阈值、声辐射力或空化/声化学反应窗口。
6. 至少完成一轮“设计-仿真-分析-优化”闭环，并形成可追溯的论文、代码、输出和支撑材料。

从科研角度看，本项目不能只证明“某个脚本能跑”。它需要回答三个递进问题：

- 目标图案能否被相位恢复算法重构成高质量声场？
- 离散厚度相位板通过真实传播后是否仍能保持目标场？
- 若用于 HDSP/DSP 材料固化，压力、曝光、空化和流场扰动是否落在可打印窗口内？

## 2. 文献基准与项目定位

`资料/s41467-024-50923-8.pdf` 对应 Derayatifar 等 2024 年 Nature Communications 论文《Holographic direct sound printing》。该论文给本项目提供了最直接的科研坐标：HDSP 使用声学全息图存储截面图像，并在目标平面诱导区域性空化和聚合；其 PDMS 打印经验窗口中，图像像素处约 `2 MPa` 是声化学反应启动的关键压力量级，继续提高压力会因声流扰动降低图案均匀性；同时，论文明确把相位板制造误差列为目标图案失真的主要来源之一。

结合外部文献，本项目应定位为“全息声场调控相位板的仿真设计与失真诊断”，而不是直接宣称已经完成“HDSP 打印工艺模型”。理由如下：

- 声学全息相位板路线成立：Melde 等 2016 年展示了 3D 打印声学全息元件可形成复杂声场，说明被动相位板是合理技术路线。
- DSP/HDSP 的材料固化核心并非单纯升温：Habibi 等 2022 年 DSP 和 Derayatifar 等 2024 年 HDSP 都强调声化学空化在 PDMS 等材料中的关键作用。
- k-Wave 适合当前数值仿真框架：k-Wave 官方说明其可处理时域声传播、非均匀介质、吸收和 GPU 加速，但它本身不替代实验或文献参数校准。
- 任务书引用的 2023-2025 年声打印/声生物制造文献说明方向很新，论文写作应强调“数值仿真支撑设计与机理诊断”，避免把未实验验证的固化预测写成已证实结论。

## 4. 当前结果的科研解读

### 4.1 相位恢复算法本身是项目的强项

`03_theoretical_phase_focus_validation/outputs/summary.json` 显示：

- `ASM Python+IASA PCC = 0.9519`
- `k-Wave Python+IASA PCC = 0.9459`
- `ASM Pure IASA PCC = 0.9484`
- `k-Wave Pure IASA PCC = 0.9418`

这说明当前目标图案、角谱传播和 IASA 相位恢复链路是成立的。也就是说，主线结果不好时，不应首先归咎于“相位恢复算法整体错误”。更合理的科研假设是：算法在理想相位边界下有效，但离散厚度相位板、出口复振幅和传播边界引入了新的失真。

### 4.2 主线全流程已经闭合，但目标场质量尚未达标

`01_mainline_full_pipeline/outputs/summary.json` 显示：

- 设计距离 `16.00 mm`，最佳平面 `18.41 mm`，焦点偏移 `2.41 mm`。
- 主线目标场 `PCC = 0.5970`，`SSIM = 0.0253`，`NMSE = 0.8435`，能量效率 `37.98%`。
- 出口幅值 `CV = 0.5115`，最小幅值比 `0.0008`。
- 固化预测 `IoU = 0.6509`，`Dice = 0.7885`，过固化 `26.64%`，欠固化 `17.57%`。

这组指标说明主线已经形成闭环，但“相位板后声场质量”远低于理想相位结果。尤其是 `SSIM = 0.0253` 和出口幅值强非均匀，意味着最终声场结构细节没有可靠保持。论文中可以把它写成“完成仿真闭环并定位退化原因”，但不能写成“最终相位板满足打印需求”。

### 4.3 出口复场退化是当前最关键问题

`04_exit_field_diagnostics/outputs/summary.json` 显示：

- 设计 ASM `PCC = 0.9519`
- 实际出口 ASM `PCC = 0.2442`
- 同相修复 `PCC = 0.2050`
- 选定相位符号修复 `PCC = 0.4202`
- 最佳 signed repaired `PCC = 0.5093`
- 出口幅值 `CV = 0.5190`
- 修复后的完整 k-Wave 和固化指标为 `NaN`

这说明目前的实体相位板模型不能被“纯相位延迟”近似充分解释。厚度板带来的出口幅度调制、局部散射、阻抗失配、数值边界或相位符号约定共同造成目标场崩塌。这个结论比继续微调固化阈值更重要。

### 4.4 固化/空化模块有价值，但不能过度解释

当前代码把空化作为主固化判据：`default_cure_model_params.m` 中 `pressure_on = 1.72e6`、`pressure_full = 1.98e6`、`pressure_stream = 2.35e6`，主线 `HDSPdebug.m` 中 `thermal_weight = 0.0`、`penalty_weight = 0.0`。这与 HDSP 文献中“PDMS 约 2 MPa 启动空化/聚合，过高压力引发 streaming”的方向一致，但仍有三个缺口：

- 主线 `summary.json` 中 `target_pressure_mpa = 1.54`，低于文献约 `2 MPa` 量级；而 02 总览图显示 ROI median `2.35 MPa`。不同模块压力标定不一致。
- 空化参数现在更像经验阈值模型，没有 Rayleigh-Plesset 气泡动力学、声流场或实验数据校准。
- `penalty_weight = 0.0` 导致 streaming/damage 只被记录或弱使用，未真正进入最终决策。

因此，固化模块适合在论文中作为“材料响应预测的探索性模块”，不适合作为核心成功指标。核心成功指标应先回到声场重构质量。

4. 清除 `pause` 交互点或提供 batch 模式，否则报告目录无法被其他机器无人工复现。

### P1：把“出口复场退化”作为主线问题

下一轮不要优先调固化阈值，应先回答：为什么 `设计 ASM PCC = 0.9519` 会变成 `实际出口 ASM PCC = 0.2442`？

建议的实验顺序：

1. 只用理想连续相位板传播，记录出口幅度和目标面 PCC。
2. 加入离散厚度量化，不加材料吸收，记录退化量。
3. 加入材料声速差和阻抗失配，记录退化量。
4. 加入吸收、有限厚度多次反射、孔径边缘，记录退化量。
5. 对每一步输出 `delta_PCC`、`exit_amp_CV`、`phase_error_std`，形成论文中的误差分解表。

### P2：相位板设计目标要从纯相位变成复场或稳健优化

目前算法把重点放在目标平面相位恢复，再把相位映射到厚度。04 的结果说明这一步不足。应尝试：

- 使用相位板出口复场作为中间目标，而不是只看目标平面强度。
- 在 IASA 目标函数中加入出口幅度均匀性约束或板厚梯度约束。
- 对厚度层数、最小基底层、相位偏置和误差扩散策略做小型正交实验。
- 引入制造误差扰动，例如层厚随机误差、声速扰动、表面偏差，评估稳健性。

### P3：固化模块降级为“候选材料响应模型”，直到被校准

固化预测可以保留，但建议在论文中明确写成“基于文献阈值的候选模型”。下一步需要：

- 统一 01 与 02 的压力标定，解释为何主线 `1.54 MPa` 可或不可触发 PDMS 空化。
- 把 `pressure_on/full/stream/damage` 与 HDSP 文献的 `~2 MPa` 和 streaming 现象建立表格对应。
- 恢复 streaming penalty 对最终选择的影响，避免只用 IoU 奖励过宽固化区域。
- 做消融：纯压力阈值、空化剂量、热辅助、streaming penalty 四组对比。
- 若论文不做实验，应避免使用“预测真实固化”措辞，改为“打印可行性窗口估计”。

### P4：代理模型先做物理基线，再扩大网络

05 的报告已经指出点模型泄漏和全场上下文重要。下一步应先做简单可解释基线：

- 厚度图、厚度梯度、局部曲率到出口幅度的线性/随机森林基线。
- 按 case 划分训练/测试，禁止同一 case 的像素同时出现在训练和验证。
- 用绝对出口场、相对修正场、目标面误差场三种 target 定义分别比较。
- 只有当物理基线无法解释且 U-Net 稳定优于基线时，再扩大网络。

### P5：论文主线建议

建议论文不要以“固化预测优化”作为主线，而以“全息相位板仿真设计与出口场退化诊断”为主线：

1. 绪论：超声3D打印、DSP/HDSP、被动声学全息相位板。
2. 理论：角谱法、IASA、相位-厚度映射、k-Wave 声传播、HDSP 空化窗口。
3. 方法：目标图案、相位恢复、离散层量化、k-Wave 三维仿真、评价指标。
4. 结果一：理想相位恢复和焦平面验证，证明算法有效。
5. 结果二：主线相位板仿真和性能评估，展示闭环及当前差距。
6. 结果三：出口复场诊断，定位相位板退化来源。
7. 讨论：材料固化预测的适用边界、待校准参数、下一步实验与优化。

这样写更符合当前证据：既有完整工程实现，又不会把尚未被物理校准的空化模型写得过满。
